สรุปภาพรวมพฤติกรรมการเงิน (Gemini AI)

วิเคราะห์พฤติกรรมการใช้จ่ายและค้นหาข้อมูลร้านค้าอัตโนมัติด้วย Gemini Flash

    สัดส่วนรายจ่ายจริงตามหมวดหมู่

    คลิกที่หมวดหมู่ใดก็ได้เพื่อดูรายการข้างใน (เรียงจากยอดใหญ่ไปเล็ก)

    ปลายทางที่โอนออกสูงสุด 6 อันดับ

    รวมยอดโอนซ้ำไปยังร้านค้าหรือผู้รับเดียวกันตลอดทั้งเดือน

    จัดหมวดหมู่รายการ

    ระบบแยกหมวดหมู่ให้อัตโนมัติแล้ว — ถ้าบางรายการไม่ตรง แก้ได้ที่นี่ ระบบจะจำไว้ใช้รอบถัดไป

    รายการธุรกรรมทั้งหมด

    ค่าเริ่มต้นเรียงจากยอดเงินมากไปน้อยเพื่อให้นึกออกง่าย สามารถสลับเรียงตามวัน-เวลาได้

    เรียงตาม:
    วัน / เวลา รายละเอียดรายการ จำนวนเงิน / คงเหลือ หมวดหมู่ หมายเหตุช่วยจำ จัดการ

    สมุดช่วยจำชื่อร้าน

    รายชื่อที่คุณเคยระบุหมวดหมู่ไว้ — ระบบจะจำและแยกอัตโนมัติในรอบถัดไป

    รายจ่ายตามช่วงเวลาของวัน

    คำนวณจากเวลาที่ทำรายการโอนออกจริงในสเตทเมนต์

    ไฟล์ PDF นี้มีการเข้ารหัสผ่าน

    กรุณากรอกรหัสผ่านเพื่อปลดล็อกเอกสาร (เช่น วันเดือนปีเกิดตามรูปแบบของธนาคาร) การถอดรหัสทำงานภายในเครื่องของคุณเท่านั้น

    รายละเอียดหมวดหมู่

    ข้อตกลงการใช้งานและนโยบายความเป็นส่วนตัว

    โปรดอ่านและยอมรับข้อกำหนดก่อนเริ่มเข้าใช้งานระบบ TangHai

    คำยืนยันความปลอดภัย: TangHai ประมวลผลและถอดรหัสเอกสารภายในเว็บเบราว์เซอร์ของผู้ใช้ 100% ไม่มีการอัปโหลดหรือจัดเก็บไฟล์สเตทเมนต์ของคุณบนเซิร์ฟเวอร์ภายนอกใด ๆ ทั้งสิ้น

    1. การประมวลผลข้อมูลภายในเครื่องของผู้ใช้ 100% (Client-Side Local Processing)

    ผู้พัฒนาเคารพและให้ความสำคัญสูงสุดต่อสิทธิความเป็นส่วนตัวและการคุ้มครองข้อมูลส่วนบุคคล (PDPA) เอกสาร e-Statement รวมถึงรายการธุรกรรม ยอดเงิน และชื่อบัญชีทั้งหมด จะถูกถอดรหัส (Decrypt) และประมวลผลในหน่วยความจำ RAM ของอุปกรณ์ของท่านเท่านั้น จะไม่มีการส่งไฟล์ PDF หรือข้อมูลสเตทเมนต์ออกจากอุปกรณ์ของท่านไปยังเซิร์ฟเวอร์ภายนอก

    2. การอนุญาตจัดเก็บข้อมูลในพื้นที่ความจำอุปกรณ์ (Local Storage Permission)

    เพื่ออำนวยความสะดวกในการใช้งานอย่างต่อเนื่อง ระบบจำเป็นต้องขออนุญาตบันทึกการตั้งค่า, ผลการจัดหมวดหมู่, และ "สมุดจำหมวดหมู่ร้านค้า (Memory Store)" ไว้ในหน่วยความจำ Local Storage ภายในเว็บเบราว์เซอร์ของอุปกรณ์ของท่าน ทั้งนี้ ข้อมูลดังกล่าวจะคงอยู่เฉพาะในเครื่องของท่าน และท่านสามารถกดปุ่ม "ล้างข้อมูลสเตทเมนต์" ได้ตลอดเวลา

    3. ข้อตกลงการใช้งานปัญญาประดิษฐ์ (AI Serverless Proxy & Anonymization)

    ในการวิเคราะห์และจำแนกหมวดหมู่ร้านค้าอัตโนมัติ ระบบจะคัดกรองส่งเฉพาะ "ชื่อร้านค้าที่ไม่คุ้นเคยที่ผ่านการตัดข้อมูลส่วนบุคคล (Anonymized & Deduplicated Merchant Strings)" ไปยัง API เพื่อช่วยจำแนกประเภทร้านค้าเท่านั้น โดยระบบจะ ตัดยอดเงินรายบรรทัดและเลขบัญชีออกก่อนส่ง เพื่อรักษาความลับขั้นสูงสุด

    4. ข้อจำกัดความรับผิดชอบ (Disclaimer)

    TangHai เป็นเครื่องมืออำนวยความสะดวกสำหรับสรุปและวิเคราะห์พฤติกรรมการใช้จ่ายส่วนบุคคลเบื้องต้น มิใช่บริการให้คำแนะนำทางการเงิน การลงทุน หรือการทำบัญชีภาษีอย่างเป็นทางการ ผู้พัฒนาจะไม่รับผิดชอบต่อความผิดพลาดอันเกิดจากความไม่สมบูรณ์ของเอกสารต้นทางจากธนาคาร

    กรุณาเลื่อนอ่านข้อตกลงในกล่องข้อความลงมาจนสุด เพื่อเปิดใช้งานการกดยินยอม

    รูปแบบสเตทเมนต์และโครงสร้างคอลัมน์ที่รองรับ

    ข้อมูลความเข้ากันได้ของธนาคารและการประมวลผลข้อมูล

    ระดับการรองรับของแต่ละธนาคาร
    ระดับที่ 1: Full Details (กสิกรไทย KBank, ไทยพาณิชย์ SCB) แยกชื่อร้านค้าและบุคคล

    สเตทเมนต์ระบุชื่อร้านค้าและชื่อผู้รับโอนโดยตรง (เช่น 7-Eleven, บจก. ไมเนอร์ ฟู้ด, TikTok Shop, บุคคลพร้อมเพย์) ระบบสามารถแยกหมวดหมู่อัตโนมัติ ผสานกับ Gemini AI และตรวจจับการโอนบัญชีตัวเอง (Self-Transfer) ได้ทันที

    ระดับที่ 2: Code-Level (กรุงไทย KTB, กรุงเทพ BBL, ทีทีบี TTB, กรุงศรี BAY) ถอดรหัสธุรกรรม

    สเตทเมนต์ระบุเป็นรหัสธุรกรรมมาตรฐาน (ISO Transaction Codes) โดยไม่มีชื่อร้านค้า ระบบใช้ Bank Transaction Code Dictionary ในการจำแนกพฤติกรรม:

    POS / EDC: ช้อปปิ้ง
    ATM / CW: กดเงินสด
    D/D: บิลหักบัญชี
    FEE / INT: ค่าธรรมเนียม / ดอกเบี้ย

    *หากมีรหัสเฉพาะ ผู้ใช้สามารถจัดหมวดหมู่ด้วยตนเอง 1 ครั้ง แล้วระบบ Smart Memory Store จะจดจำรหัสนั้นไว้ตลอดไป

    โครงสร้างคอลัมน์มาตรฐาน
    1. วันที่ (Date)
    2. เวลา (Time)
    3. ช่องทาง (Channel)
    4. เงินออก (Debit)
    5. เงินเข้า (Credit)
    6. คงเหลือ (Balance)
    7. รายละเอียด (Description รวมหลายบรรทัด)
    หากข้อมูลบางจุดขาดหายไป
    • ชื่อเจ้าของบัญชีขาดหาย: บางธนาคารเซ็นเซอร์ชื่อหรือพิมพ์เฉพาะเลขที่บัญชี คุณสามารถกดปุ่ม "แก้ไข / ระบุชื่อ" บนแถบข้อมูลบัญชี เพื่อใส่ชื่อตัวเองได้ทันที ระบบจะนำชื่อไปจับคู่ตัดยอดโอนบัญชีตัวเอง (Self-Transfer) ให้อัตโนมัติ
    • รวมชื่อข้ามธนาคาร: เมื่อกด "+ เพิ่มสเตทเมนต์" จากธนาคารอื่น ระบบจะเก็บชื่อเจ้าของจากทุกธนาคารไว้ เพื่อให้เวลาโอนข้ามบัญชีตัวเอง (เช่น SCB ↔ KBank) ยอดเงินไม่บวม
    • จัดหมวดหมู่เฉพาะตัว: แต่ละคนมีค่าใช้จ่ายที่ไม่เหมือนกัน (เช่น ค่าหอพัก, ทาสสัตว์เลี้ยง, ค่าเกม) สามารถแตะหมวดหมู่แนะนำ หรือสร้างหมวดหมู่ใหม่ได้ไม่จำกัด
