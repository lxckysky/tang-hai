# 💸 TangHai AI (ตังค์หายไปไหน?)
> **Smart Bank Statement Analyzer with 3-Tier AI Categorization & Custom Merchant Memory**  
> โปรเจกต์รอบสัมภาษณ์ **Young Webmaster Camp (YWC) — สาขา Web Programming**

---

## 🎯 ที่มาของปัญหา (Problem Statement)
เวลาสิ้นเดือนที่รู้สึกว่า **"ตังค์หายไปไหนหมด"** การมานั่งพิมพ์จดรายรับ-รายจ่ายเองทุกวันมักทำไม่สำเร็จเพราะคนไทยสแกนจ่ายผ่าน QR PromptPay กันหมดแล้ว แต่พอขอไฟล์ **e-Statement (PDF)** รายเดือนจากธนาคารมาดู กลับเจอปัญหาว่า:
1. ไฟล์ PDF ติดรหัสผ่าน ต้องปลดล็อกก่อนถึงจะดึงข้อมูลได้
2. รายการโอนเงินมีทั้ง **ชื่อร้านในหมายเหตุ**, **ชื่อบริษัทจดทะเบียนที่ดูยาก** (เช่น `MINOR FOOD HOLDING`, `OMISE - TIKTOK SHOP`) และ **ชื่อบัญชีบุคคลธรรมดา/Wallet** (เช่น `PromptPay นายวีรยุทธ`, `SIPS TRUE MONEY`) ที่ไม่รู้ว่าโอนไปซื้ออะไร
3. ร้านประจำที่เป็นชื่อบัญชีบุคคล โอนซ้ำๆ ทุกสัปดาห์ ถ้าไม่มีระบบจำชื่อ ต้องมานั่งไล่แก้ใหม่ทุกรอบ

## ✨ ฟีเจอร์หลัก (Key Features)
1. **🔐 Client-Side PDF Password Unlock & Parser (`js/pdfParser.js`):**
   * รองรับการอัปโหลดไฟล์ PDF Statement ธนาคารที่ติดรหัสผ่าน โดยถอดรหัสและสกัดตารางใน Browser ของผู้ใช้โดยตรง (ปลอดภัย 100% ไม่ส่งไฟล์ขึ้นเซิร์ฟเวอร์)
2. **🤖 3-Tier Smart Categorization & API Cost Optimization (`js/categorizer.js`):**
   * **ชั้นที่ 1:** เช็กจากสมุดช่วยจำ (`localStorage`) และรหัสธุรกรรมที่ชัดเจน (`X1` เงินเข้า / `CDM` กดเงินสด) ฟรี 0 บาท
   * **ชั้นที่ 2:** รวบรวมเฉพาะชื่อบริษัทที่ไม่ซ้ำกัน (**Deduplication**) ให้ AI ช่วยเดาหมวดหมู่จากชื่อบริษัท ประหยัดการยิง API ซ้ำซ้อนได้กว่า 40–60%
   * **ชั้นที่ 3:** แยกรายการที่เป็นชื่อบุคคลหรือไม่ชัดเจนไว้ในหมวด `❓ รอเจ้าของระบุเอง`
3. **📌 Remember Rule — ระบุครั้งเดียวจำทั้งเดือน (`js/memoryStore.js`):**
   * เมื่อเจ้าของตรวจสอบและระบุชื่อช่วยจำให้บัญชีใดเพียง 1 ครั้ง (เช่น `นายวีรยุทธ เซ่งนาค` = `ร้านข้าวประจำ`) ระบบจะอัปเดตทุกรายการที่โอนให้คนเดียวกันนี้ทั้งเดือนให้อัตโนมัติ และจำไว้ใช้ในเดือนถัดไปทันที
4. **📊 Financial Leak Dashboard (`js/app.js`):**
   * สรุปสัดส่วนค่าใช้จ่ายตามหมวดหมู่, จัดอันดับ Top 5 บัญชีดูดตังค์ประจำเดือน และตรวจจับพฤติกรรมการโอนเงินช่วงดึก (00:00 - 04:59 น.)
