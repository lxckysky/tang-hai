# TangHai (ตังค์หาย) — ระบบวิเคราะห์และจัดหมวดหมู่รายการเดินบัญชีธนาคารอัตโนมัติ

เว็บแอปพลิเคชันสำหรับปลดล็อก สกัดตาราง และจัดหมวดหมู่ไฟล์รายการเดินบัญชีธนาคารอิเล็กทรอนิกส์ (PDF e-Statement) อัตโนมัติ ออกแบบด้วยสถาปัตยกรรม **100% Client-Side PDF Parsing** ร่วมกับ **Hybrid AI Categorization & Web Search Grounding** เพื่อช่วยวิเคราะห์พฤติกรรมการใช้จ่ายและคำนวณ **"รายจ่ายใช้ชีวิตจริง (True Personal Spend)"** โดยไม่ต้องส่งไฟล์เอกสารการเงินออกจากอุปกรณ์ของผู้ใช้

## 1. ที่มาและวัตถุประสงค์ของระบบ (Background & Motivation)

การตรวจสอบรายรับ-รายจ่ายย้อนหลังจากไฟล์ **e-Statement (PDF)** รายเดือนของธนาคารมักมีข้อจำกัดในการใช้งานจริง 4 ประการ:

1. **ความเป็นส่วนตัวและไฟล์ติดรหัสผ่าน:** เอกสารสเตทเมนต์เป็นข้อมูลการเงินส่วนบุคคลและมักถูกล็อกด้วยรหัสผ่าน ผู้ใช้จึงไม่ต้องการอัปโหลดไฟล์ PDF ทั้งฉบับขึ้นเซิร์ฟเวอร์ภายนอก
2. **ยอดเงินออกบวมจากการโอนข้ามบัญชีตัวเอง (Self-Transfer Distortion):** ผู้ใช้ที่มีหลายบัญชีธนาคารและโอนเงินหมุนเวียนระหว่างบัญชีตัวเอง จะพบว่ายอดเงินออกรวมในสเตทเมนต์สูงกว่ารายจ่ายจริงหลายเท่า
3. **รายการหารค่าใช้จ่ายและเงินผ่านมือ (Split Bills & Pass-Throughs):** การสำรองจ่ายค่าอาหารให้กลุ่มเพื่อนแล้วรับโอนคืน หรือเงินที่โอนเข้าแล้วโอนออกทันทีในจำนวนเท่ากัน ทำให้สัดส่วนค่าใช้จ่ายคลาดเคลื่อน
4. **ชื่อรายการในสเตทเมนต์ตีความยาก:** รายการเดินบัญชีมีทั้งชื่อนิติบุคคลจดทะเบียน ชื่อร้านค้าย่อย รหัสธุรกรรมธนาคาร และชื่อบุคคล PromptPay ที่ต้องอาศัยการค้นหาข้อมูลประกอบและการจดจำชื่อผู้รับโอนซ้ำในเดือนถัดไป

## 2. คู่มือการใช้งานระบบ (User Guide)

### 2.1 การเริ่มต้นใช้งานและอัปโหลดไฟล์สเตทเมนต์
1. เปิดเข้าสู่เว็บไซต์ [https://tang-hai-nu.vercel.app/](https://tang-hai-nu.vercel.app/) (เมื่อเข้าใช้งานครั้งแรก ระบบจะแสดงข้อตกลงการใช้งานและนโยบายความเป็นส่วนตัวให้อ่านและกดยินยอม)
2. **กรณีมีไฟล์ PDF e-Statement:**
   - ลากไฟล์ PDF สเตทเมนต์ (รองรับการเลือกพร้อมกันหลายไฟล์) ลงในกล่องอัปโหลด หรือกดปุ่มเพื่อเลือกไฟล์จากอุปกรณ์
   - หากไฟล์ PDF ติดรหัสผ่าน ระบบจะแสดงหน้าต่างให้กรอกรหัสผ่านเพื่อปลดล็อกไฟล์ภายในเบราว์เซอร์ทันที
3. **กรณีต้องการทดลองใช้งานด้วยข้อมูลตัวอย่าง (Demo Mode):**
   - กดปุ่ม **"สเตทเมนต์ SCB (Full Details)"** เพื่อดูตัวอย่างการวิเคราะห์สเตทเมนต์ที่มีชื่อร้านค้า ชื่อบริษัท การโอนข้ามบัญชีตัวเอง และรายการโอนให้บุคคล
   - กดปุ่ม **"สเตทเมนต์ KTB (Code-Level)"** เพื่อดูตัวอย่างการถอดรหัสสเตทเมนต์ที่ใช้รหัสธุรกรรมธนาคาร (`POS`, `CW`, `D/D`, `FE01`)
4. **การรวมสเตทเมนต์หลายเดือนหรือหลายธนาคาร:**
   - กดปุ่ม **`+ เพิ่ม`** บนแถบด้านบนเพื่ออัปโหลดไฟล์สเตทเมนต์เดือนอื่นหรือธนาคารอื่นเพิ่มเติม ระบบจะรวมรายการทั้งหมดเข้าด้วยกันและรวบรวมรายชื่อเจ้าของบัญชีจากทุกไฟล์เพื่อใช้ตัดยอดโอนข้ามบัญชีตัวเองอัตโนมัติ

### 2.2 การใช้งานทั้ง 4 หน้าจอหลัก
* **แท็บที่ 1 — ภาพรวม (Overview):**
  - แสดงการ์ดสรุป **เงินโอนเข้าทั้งหมด**, **รายจ่ายใช้ชีวิตจริง (หักโอนบัญชีตัวเองและเงินผ่านมือออกแล้ว)**, **รายการช่วงดึก (00:00 - 05:00 น.)** และ **รายการที่ยังระบุไม่ได้**
  - แสดง **สรุปภาพรวมพฤติกรรมการเงิน** ที่วิเคราะห์จากข้อมูลจริงในสเตทเมนต์
  - แสดง **สัดส่วนรายจ่ายแยกตามหมวดหมู่** (สามารถคลิกที่แต่ละหมวดเพื่อเปิดดูรายการย่อยภายในหมวดนั้นได้ทันที) และ **อันดับผู้รับโอนที่จ่ายออกสูงสุด**
* **แท็บที่ 2 — จัดหมวดหมู่ (Priority Review & Custom Categories):**
  - รวบรวมเฉพาะรายการที่ยังไม่ทราบหมวดหมู่หรือรายการโอนให้บุคคล มาจัดกลุ่มตามชื่อผู้รับและ **เรียงลำดับจากยอดเงินรวมมากที่สุดไปน้อยที่สุด** เพื่อให้จัดการรายการสำคัญได้รวดเร็ว
  - สามารถเพิ่มหมวดหมู่ใหม่ตามไลฟ์สไตล์ของตนเอง หรือเลือกจากพรีเซ็ตหมวดหมู่ที่มีให้ได้ทันที
* **แท็บที่ 3 — รายการทั้งหมด (All Transactions):**
  - แสดงตารางรายการเดินบัญชีทั้งหมด พร้อมระบบค้นหา กรองตามประเภทรายการ สวิตช์ซ่อนรายการโอนบัญชีตัวเอง และตัวเลือกการจัดเรียงลำดับ (`ยอดเงิน มาก -> น้อย`, `ยอดเงิน น้อย -> มาก`, `วัน-เวลา ตามลำดับสเตทเมนต์`)
  - เมื่อเปลี่ยนหมวดหมู่หรือพิมพ์หมายเหตุช่วยจำในแถวใดแล้วกดปุ่ม **บันทึก** ระบบจะอัปเดตทุกรายการที่มีชื่อผู้รับเดียวกันในสเตทเมนต์ให้พร้อมกันทันที
* **แท็บที่ 4 — สมุดจำ & เวลา (Memory Store & Time Breakdown):**
  - สรุปยอดโอนเข้า-ออกระหว่างบัญชีของตนเอง แสดงสถิติการใช้จ่ายตามช่วงเวลาของวัน และจัดการรายชื่อร้านค้า/บุคคลที่บันทึกไว้ในสมุดช่วยจำ (`localStorage`)
* **การส่งออกข้อมูล (Export CSV):**
  - กดปุ่ม **`CSV`** บนแถบด้านบนเพื่อดาวน์โหลดตารางรายการที่จัดหมวดหมู่และใส่หมายเหตุเรียบร้อยแล้วออกไปใช้งานต่อใน Excel หรือ Google Sheets (รองรับภาษาไทย UTF-8 BOM)

### 3.1 100% Client-Side PDF Decryption & Universal Multi-Bank Parser (`js/pdfParser.js`)
* **ถอดรหัสเอกสารในเครื่องผู้ใช้:** ใช้ `PDF.js` ปลดล็อกรหัสผ่านและอ่านข้อมูลพิกัดข้อความในเบราว์เซอร์ โดยไม่มีการส่งไฟล์ PDF หรือรหัสผ่านออกนอกเครื่องแม้แต่ไบต์เดียว
* **Smart Multi-Bank Column Layout Engine:** ตรวจจับโครงสร้างคอลัมน์ของแต่ละธนาคารอัตโนมัติ (KBank, SCB, BBL, Krungthai, ttb, Krungsri):
  * **ดึงชื่อเจ้าของบัญชีครบถ้วน:** รองรับคำนำหน้า ด.ญ., ด.ช., เด็กหญิง, เด็กชาย, นาย, นางสาว, น.ส., นาง, MR., MS. ฯลฯ
  * **รองรับเลขที่บัญชี 4 กลุ่ม:** เช่น `011-8-35708-6` ของกสิกรไทย และ 3 กลุ่มของไทยพาณิชย์
  * **Multi-line Description Merger:** ผสานข้อความคำอธิบายรายการที่ยาวเกิน 1 บรรทัด (เช่น `CPN SLY FOOD PATIO (ชื่อบัญชี: บมจ. เซ็นทรัลพัฒนา)` หรือ `TikTok Shop (Serviced by PIPO)`) กลับเข้าสู่รายการเดียวกันอย่างสมบูรณ์
* **Universal Balance-Delta Parser:** แทนที่จะเขียน Regex เจาะจงแต่ละธนาคาร ระบบใช้สมการคณิตศาสตร์เปรียบเทียบผลต่างยอดคงเหลือ:
  $$\Delta \text{Balance} = \text{currBalance} - \text{prevBalance}$$
  * ถ้า $\Delta \text{Balance} > 0$ $\rightarrow$ เงินเข้า (`Credit`)
  * ถ้า $\Delta \text{Balance} < 0$ $\rightarrow$ เงินออก (`Debit`)  
  ช่วยให้รองรับสเตทเมนต์ได้ทุกธนาคารอย่างแม่นยำ แม้แต่ละธนาคารจะเรียงคอลัมน์ต่างกัน
* **Multi-Statement Cross-Bank Merger:** กดปุ่ม **`+ เพิ่มสเตทเมนต์`** เพื่อนำบัญชีที่ 2 และ 3 จากต่างธนาคารมารวมเป็นก้อนเดียวได้

### 3.2 การตัดยอดโอนบัญชีตัวเอง & ตรวจจับเงินหารเพื่อน (`js/categorizer.js`)
* **Self-Transfer Elimination & Stem Matching:** ดึงชื่อเจ้าของบัญชีจากหัวกระดาษ และตรวจจับธุรกรรมที่ชื่อผู้รับตรงกับชื่อตนเอง (รองรับการตัดคำด้วย `++` ของธนาคาร เช่น `ด.ญ. ทอฝัน สุทธิ++` หรือ `นาย ศาศวรรต จิตรส+`) แล้วแยกออกเป็นหมวดหมู่ `SELF_TRANSFER` ไม่นับรวมใน **รายจ่ายใช้ชีวิตจริง (True Personal Spend)**
* **Split & Pass-Through Detector:** ตรวจจับธุรกรรมที่มีเงินเข้า-ออกเท่ากันในวันเดียวกัน (`PASS_THROUGH` / `REIMBURSED`) หรือมียอดโอนเข้าเท่าๆ กันจากหลายคนก่อนจ่ายบิลก้อนใหญ่ (`SPLIT_BILL`) พร้อมแสดงป้ายกำกับบนตารางทันที
* **3-Tier Categorization Flow:**
  1. **Tier 1 (Memory & Regex Rules):** ตรวจสอบจากประวัติที่ผู้ใช้เคยตั้งชื่อไว้ในเครื่อง (`localStorage`) และกฎร้านค้าพื้นฐานฟรี 0 บาท
  2. **Tier 2 (Deduplicated AI Batch & Search Grounding):** กรองเฉพาะชื่อร้านค้าที่ไม่ซ้ำกัน (`Set Deduplication`) แบ่งส่งเป็น Batch ไปให้ Gemini AI ค้นหาข้อมูลธุรกิจและวิเคราะห์หมวดหมู่ ช่วยประหยัดโควตาและลด Token การเรียก API ได้กว่า 70–85%
  3. **Tier 3 (Priority Review Queue):** ดึงรายการที่ไม่รู้จักมาเรียงจาก **ยอดเงินมากสุด $\rightarrow$ น้อยสุด** พร้อมแสดง **คำใบ้จาก AI** เพื่อให้ระบุได้เสร็จในไม่กี่คลิก

### 3.3 Zero-Config Serverless AI Proxy & Seamless Fallback (`api/gemini.js`)
* เชื่อมต่อ Gemini API ผ่าน Vercel Serverless Function เพื่อซ่อน `GEMINI_API_KEY` ไว้ในเซิร์ฟเวอร์ เมื่อผู้ใช้อัปโหลดไฟล์หรือเลือกข้อมูลตัวอย่าง ระบบจะวิเคราะห์ให้อัตโนมัติทันทีโดยไม่ต้องตั้งค่า API Key เอง
* มาพร้อมระบบ **Model Fallback Chain** (`gemini-3.5-flash` $\rightarrow$ `gemini-3.8-flash` $\rightarrow$ `gemini-3.5-flash-lite` $\rightarrow$ `gemini-2.5-flash`) และหากออฟไลน์จะสลับไปใช้ **Smart Heuristic Rule Engine** ทันทีโดยไม่ทำให้หน้าเว็บค้าง

### 3.4 Mobile-First Responsive Dashboard (`index.html`, `js/app.js`)
* รองรับทุกอุปกรณ์ทั้ง Desktop (ตารางข้อมูลละเอียด) และ iPhone/Mobile (การ์ดรายการแนวตั้ง + Bottom Tab Bar)
* มีแถบ **สัดส่วนรายจ่ายภาพรวม (Stacked Distribution Bar)** และระบบ **Category Modal Drill-down** เพื่อเจาะดูรายการย่อยในแต่ละหมวดได้ทันที

```text
tang-hai/
```

## 5. การติดตั้งและรันโปรเจกต์ในเครื่อง (Local Development & Deployment)

### การรันทดสอบในเครื่อง (Local Development)
```bash
git clone https://github.com/lxckysky/tang-hai.git
cd tang-hai
npm start
# หรือใช้ Vercel CLI เพื่อจำลองการทำงานของ Serverless Function (/api/gemini):
npx vercel dev
```

### การ Deploy ขึ้น Vercel
1. Push โค้ดขึ้น GitHub Repository
2. สร้างโปรเจกต์บน [vercel.com](https://vercel.com) และเลือก Repository `tang-hai`
3. ตั้งค่า Environment Variable ในหน้า Project Settings:
   * **Key:** `GEMINI_API_KEY`
   * **Value:** ใส่ API Key จาก [Google AI Studio](https://aistudio.google.com/)
4. กด **Deploy** เพื่อเผยแพร่เว็บไซต์ขึ้นสู่ Production URL (เช่น `https://tang-hai-nu.vercel.app/`)
